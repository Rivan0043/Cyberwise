## 📌 1. Latar Belakang & Masalah
Maraknya **berita palsu (hoaks)**, **kejahatan *phishing***, dan **rekayasa sosial (*social engineering*)** menjadi ancaman nyata di Indonesia. Sebagian besar kasus kerugian digital terjadi bukan karena kegagalan sistem keamanan, melainkan rendahnya kesadaran dan ketelitian pengguna (*human error*).

**CyberWise** hadir sebagai media edukasi berbasis simulator interaktif yang menguji ketelitian pengguna dalam mendeteksi ancaman digital secara langsung dalam lingkungan yang aman.

---

## 💡 2. Fitur Utama

- 💬 **Interactive Case Simulator (Click-to-Inspect):** Mengadaptasi antarmuka aplikasi pesan populer (WhatsApp/SMS/Email). Pengguna dapat mengeklik area pesan untuk menguji keaslian pengirim dan tautan.
- 🧮 **Suspicious Text & Risk Score Checker:** Analisis teks pesan menggunakan algoritma pembobotan risiko berbasis pola indikator ancaman (*rule-based risk scoring*).
- 🏆 **Gamifikasi & Lencana Pencapaian:** Sistem pengumpulan skor, akurasi, dan pembukaan lencana kewaspadaan secara instan.
- 📜 **Canvas Certificate Generator (HD 1200x840):** Generasi sertifikat digital kompetensi Literasi Digital bertanda tangan yang dapat diunduh langsung dalam format PNG.
- 🔊 **Web Audio Synthesizer:** Efek suara responsif tanpa kebergantungan file audio eksternal (*zero dependency*).

## 🛠️ 3. Tech Stack

Proyek ini dibangun murni menggunakan teknologi web standar tanpa kebergantungan *framework* eksternal:

| Komponen | Teknologi | Keterangan |
| :--- | :--- | :--- |
| **Structure** | `HTML5` | Tata letak semantik dan komponen interaktif. |
| **Styling** | `CSS3` | Design Dark/Cyberpunk Mode, Flexbox/Grid, & CSS Animations. |
| **Logic** | `JavaScript (Vanilla JS)` | Pengolahan kuis, manipulasi DOM, Audio API, & Canvas Rendering. |
| **Data Source** | `JSON` | Format terpisah (`data/cases.json`) untuk pengelolaan skenario kuis. |
